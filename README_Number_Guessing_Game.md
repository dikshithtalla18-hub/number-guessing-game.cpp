# Number Guessing Game (C++)

## Project Description

A console-based Number Guessing Game written in C++. The program
generates a random number between **1 and 100**, provides **Too High**
or **Too Low** hints, counts attempts, displays a final score, and
allows the user to replay.

## Objective

-   Master random number generation using `srand(time(0))`
-   Practice conditional logic
-   Track user attempts
-   Implement replay functionality

## Features

-   Random number (1--100)
-   Too High / Too Low hints
-   Attempt counter
-   Final score
-   Replay option
-   Exit message
